# 墨锭试磨室

墨锭试磨领用闭环：建档 → 领用 → 连续试磨 → 归还，全程操作可追溯。

## 运行

```bash
npm start
```

访问 <http://localhost:3037>。数据保存在 `data/ink-stick-testing.json`（首次启动自动播种；旧版数据自动迁移为事件流模型）。

可用环境变量：`PORT`（端口，默认 3037）、`INK_DB`（数据文件路径）。

## 流转规则

```
待试磨 ──领用──▶ 试磨中 ──归还(完成)──▶ 已试磨
已试磨 ──领用──▶ 试磨中 ──归还(留观)──▶ 重点观察
重点观察 ──领用──▶ 试磨中
待试磨/已试磨/重点观察 可直接标记/取消重点观察
```

- 墨锭编号唯一，新墨锭一律为「待试磨」。
- 同一墨锭同一时刻只能被一人领用；重复领用、非法跳转返回 **409** 并附中文原因。
- 试磨记录（纸张、加水量、出墨速度、墨色层次、沉淀、评分 0–100）仅在「试磨中」可连续追加。
- 每次领用/归还/试磨都记录操作人、时间、位置、备注，可在卡片「操作履历」中追溯。
- 所有写入经单队列串行处理，写文件采用 `临时文件 + fsync + rename` 原子替换；变更请求支持 `X-Idempotency-Key`，并发或重试只生效一次。
- 列表支持状态筛选（顶部统计卡也可点选）、关键词搜索，展示各状态数量与每锭最近操作。
- 页面为响应式，桌面双栏、手机单栏，弹窗在手机上为底部抽屉式。

## API 摘要

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| GET | `/api/items?status=&q=` | 列表（含 stats、最近操作） |
| GET | `/api/stats` | 各状态数量 |
| POST | `/api/items` | 建档（编号唯一，初始待试磨） |
| POST | `/api/items/:code/checkout` | 领用 `{operator,position,note}` |
| POST | `/api/items/:code/tests` | 追加试磨记录（六字段 + 评分） |
| POST | `/api/items/:code/return` | 归还 `{operator,position,toStatus,note}` |
| POST | `/api/items/:code/watch` | 标记/取消重点观察 `{operator,unwatch}` |

写操作可带 `X-Idempotency-Key` 头实现幂等重放。

## 验证

```bash
npm run verify
```

启动真实 HTTP 服务做端到端校验（43 项）：并发领用只成功一次、幂等重放、非法跳转拒绝原因、连续试磨、筛选统计、原子写无半截文件、重启一致、旧数据迁移。
